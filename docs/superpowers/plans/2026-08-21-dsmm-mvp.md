# DSMM v0.1 MVP Implementation Plan

> **For agentic workers:** Use the subagent-driven-development skill to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `dsmm/` as an ocmm-repo subtree package that delivers a dsh-native, opt-in `deepwork` mode bundle for DSMM v0.1.

**Architecture:** DSMM is a standalone TypeScript ESM dsh bundle under `dsmm/`, modelled after public dsh plugin examples and oh-dsh's bundle/profile structure. The Host plugin uses Cordis/dsh services directly: settings are registered under the `dsmm` namespace when `ctx.settings` is available, bundled skills are registered with `ctx.skills.register()` when `ctx.skills` is available, `deepwork/mode` is persisted as session state, `dsmm:deepwork` is rendered only while that state is active, and `/deepwork [off|message]` toggles the mode through the command plane. Docker support is a disposable smoke surface; normal development proof is tests, typecheck, and build.

**Tech Stack:** TypeScript ESM, Node.js 22+ `node:test`, pnpm workspace, `@deepseek-ai/schemastery`, DeepSeek Harness Cordis services (`ctx.systemPrompt`, optional `ctx.settings`, `ctx.skills`, `ctx.commands`, `agent/pre-step`), Cordis patch YAML, optional Docker smoke test.

**Spec:** `dsmm/docs/design.md`; supporting references: `dsmm/docs/roadmap.md`, `dsmm/docs/research/oh-dsh.md`, `dsmm/docs/research/deepseek-v4-pro.md`

**Global Constraints:**
- Implement a dsh-native bundle; do not simulate OpenCode hooks.
- `deepwork` must be opt-in as a dsmm-provided dsh custom mode; never globally enable it.
- Current public dsh docs expose `@deepseek-ai/dsh-plan-mode`, not a generic arbitrary-mode package; implement DSMM's own `deepwork` mode plugin using plan-mode semantics as reference.
- Register a fixed internal `deepwork/mode` session event. `modeName` config controls the slash command and prompt label only; it does not rename the persisted event in v0.1.
- Register system-prompt section `dsmm:deepwork`; return prompt text only while deepwork mode is active.
- Register `/deepwork [off|message]` or `/<modeName> [off|message]` only when `ctx.commands` is composed; command toggles mode through a pending selection committed at the next accepted `agent/pre-step`, matching dsh plan-mode semantics.
- Use the official `createUserMessage()` helper from `@deepseek-ai/dsh-llm` when command input is steered to the agent.
- Register MVP skills through `ctx.skills.register()` instead of relying on package-root-relative `dsh-skill-filesystem` paths.
- MVP excludes exit-tool approval, UI/client work, publishing, tool guard parity, runtime fallback, idle continuation, and MCP/LSP packaging.
- DSMM skill files live under `dsmm/skills/`; do not modify existing ocmm `skills/v1/` prompts for this MVP.
- Docker smoke is optional; mandatory acceptance is unit tests, typecheck, build, root regression checks, and static package/patch validation.
- Do not commit from subagents; the orchestrator owns git writes after verification.

**Implementation rulings applied after review feedback:**
- Keep the public plugin `inject` list to `['systemPrompt']`; optional `settings`, `skills`, and `commands` are attached only through `ctx.inject()` when present, or through direct properties only in plain-object unit-test doubles that actually own those properties. Do not directly read absent Cordis service properties.
- Read DeepSeek model identity from `context.agent?.options?.model`; do not rely on a non-standard `AssembleContext.model` field.
- Emit the `deepwork/mode` type augmentation through `src/dsh-events.ts` and re-export its public type from the package root so built declarations include `lib/dsh-events.d.ts` and `lib/index.d.ts` references it.
- Keep root `pnpm-workspace.yaml` limited to workspace membership; do not change repo-wide `autoInstallPeers`. The Docker smoke creates its own temporary container workspace config with `autoInstallPeers: false`.
- Source files use `.js` relative imports for package-quality declarations. Package tests run `pnpm run build` first and import runtime modules from `lib/*.js`.
- Keep `@deepseek-ai/dsh-session` out of dsmm dependencies in v0.1 because its current peer graph asks pnpm for unpublished `@deepseek-ai/dsh-type-meta`; the augmentation is emitted as an optional declaration module and packaged through `lib/`.

export function resolveConfig(config: DsmmPluginConfig = {}): DsmmSettings {
  return {
    modeName: config.modeName ?? DEFAULT_DSMM_SETTINGS.modeName,
    defaultActive: config.defaultActive ?? DEFAULT_DSMM_SETTINGS.defaultActive,
    promptOrder: config.promptOrder ?? DEFAULT_DSMM_SETTINGS.promptOrder,
    deepseekV4ProCalibration: config.deepseekV4ProCalibration ?? DEFAULT_DSMM_SETTINGS.deepseekV4ProCalibration,
    skills: { ...DEFAULT_DSMM_SETTINGS.skills, ...config.skills }
  };
}

export function registerSettings(ctx: DshContext, config: DsmmPluginConfig = {}): () => DsmmSettings {
  const base = resolveConfig(config);
  let getSettings = () => base;

import type { DshAgent, DshContext, DshSession, DshSessionEvent, PreStepDecision, PreStepFrame } from "./dsh-types.js";

export const DEEPWORK_MODE_EVENT = "deepwork/mode";
type PendingIntent = { active: boolean };
export type DeepworkSelectionOutcome = "committed" | "pending" | "unchanged";

function activeFromEvent(event: DshSessionEvent): boolean | undefined {
  if (event.type !== DEEPWORK_MODE_EVENT) return undefined;
  const data = event.data;
  return typeof data === "object" && data !== null && "active" in data && typeof data.active === "boolean"
    ? data.active
    : undefined;
}

export function isDeepworkActive(events: readonly DshSessionEvent[] = [], defaultActive = false): boolean {
  let active = defaultActive;
  for (const event of events) active = activeFromEvent(event) ?? active;
  return active;
}

export function hasOpenTurn(events: readonly DshSessionEvent[] = []): boolean {
  let open = false;
  for (const event of events) {
    if (event.type === "turn/start") open = true;
    else if (event.type === "turn/end") open = false;
  }
  return open;
}

export class DeepworkModeController {
  private readonly pending = new WeakMap<DshSession, PendingIntent>();

  constructor(ctx: DshContext) {
    ctx.on?.("agent/pre-step", async (frame: PreStepFrame, next: () => Promise<PreStepDecision>) => {
      const decision = await next();
      const intent = this.pending.get(frame.agent.session);
      if (decision.kind === "reject" || frame.signal.aborted || intent === undefined) return decision;
      await this.commit(frame.agent.session, intent.active);
      return decision;
    });
  }

  active(agent: DshAgent | undefined, defaultActive: boolean): boolean {
    if (agent === undefined) return false;
    return this.pending.get(agent.session)?.active ?? isDeepworkActive(agent.session.events, defaultActive);
  }

  async select(agent: DshAgent, active: boolean, defaultActive = false): Promise<DeepworkSelectionOutcome> {
    const current = this.active(agent, defaultActive);
    if (current === active && !this.pending.has(agent.session)) return "unchanged";
    this.pending.set(agent.session, { active });
    if (hasOpenTurn(agent.session.events)) return "pending";
    await this.commit(agent.session, active);
    return "committed";
  }

  private async commit(session: DshSession, active: boolean): Promise<void> {
    await session.append(DEEPWORK_MODE_EVENT, { active });
    this.pending.delete(session);
  }
}

import { createUserMessage } from "@deepseek-ai/dsh-llm";
import type { DshCommandInvocation, DshContext } from "./dsh-types.js";
import type { DsmmSettings } from "./settings.js";
import type { DeepworkModeController } from "./state.js";

export interface DeepworkCommandInput {
  action: "on" | "off";
  message: string;
}

export function parseDeepworkCommandInput(rawInput: string): DeepworkCommandInput {
  const message = rawInput.trim();
  return message === "off" ? { action: "off", message: "" } : { action: "on", message };
}

async function handleDeepworkCommand(
  controller: DeepworkModeController,
  getSettings: () => DsmmSettings,
  invocation: DshCommandInvocation
): Promise<{ kind: "success"; text: string }> {
  const parsed = parseDeepworkCommandInput(invocation.rawInput);
  await controller.select(invocation.agent, parsed.action === "on", getSettings().defaultActive);
  if (parsed.action === "on" && parsed.message !== "") {
    await invocation.agent.steer?.(createUserMessage({
      content: [{ type: "text", text: parsed.message }],
      source: { kind: "user" }
    }));
  }
  return parsed.action === "on"
    ? { kind: "success", text: "Entering deepwork mode." }
    : { kind: "success", text: "Leaving deepwork mode." };
}

export function registerDeepworkCommand(ctx: DshContext, controller: DeepworkModeController, getSettings: () => DsmmSettings): void {
  ctx.inject?.(["commands"], (services) => {
    services.commands?.register({

```ts
import { readFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";
import type { DshContext, DshSkillRegistration } from "./dsh-types.js";

export const MVP_SKILL_NAMES = ["brainstorming", "writing-plans", "requesting-code-review", "receiving-code-review"] as const;

const packageRoot = dirname(dirname(fileURLToPath(import.meta.url)));

export function parseSkillMarkdown(markdown: string): { name: string; description: string; content: string } {
  const match = /^---\r?\n([\s\S]*?)\r?\n---\r?\n?([\s\S]*)$/u.exec(markdown);
  if (match === null) throw new Error("skill markdown must start with YAML frontmatter");
  const frontmatter = match[1];
  const name = /^name:\s*(.+)$/mu.exec(frontmatter)?.[1]?.trim();
  const description = /^description:\s*(.+)$/mu.exec(frontmatter)?.[1]?.trim().replace(/^['"]|['"]$/g, "");
  if (name === undefined || description === undefined) throw new Error("skill frontmatter needs name and description");
  return { name, description, content: match[2] };
}

function loadSkill(name: string): DshSkillRegistration {
  const directory = join(packageRoot, "skills", name);
  const parsed = parseSkillMarkdown(readFileSync(join(directory, "SKILL.md"), "utf8"));
  return {
    name: parsed.name,
    description: parsed.description,
    content: parsed.content,
    source: "bundled",
    provider: "dsmm",
    resourceBase: { kind: "directory", path: directory },
    invocation: { modelInvocable: true, userInvocable: true }
  };
}

export function registerBundledSkills(ctx: DshContext, getSettings: () => { skills: Record<(typeof MVP_SKILL_NAMES)[number], boolean> }): void {
  const register = (skills: DshContext["skills"]): void => {
    if (skills === undefined) return;
    const settings = getSettings();
    for (const name of MVP_SKILL_NAMES) {
      if (settings.skills[name]) skills.register(loadSkill(name));
    }
  };
  if (ctx.inject !== undefined) {
    ctx.inject(["skills"], services => register(services.skills));
    return;
  }
  register(ctx.skills);
}
```
