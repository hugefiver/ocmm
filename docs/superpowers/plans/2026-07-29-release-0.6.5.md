# ocmm 0.6.5 Release Implementation Plan

> **For agentic workers:** Use the subagent-driven-development skill to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Assemble, review, publish, and locally install the complete `ocmm@0.6.5` release while keeping native LSP version `0.3.2`, preserving the five active locked native processes, and binding publication to one dual-approved committed-range identity.

**Architecture:** Treat the release as a fail-closed state machine with eight serial boundaries: freeze and commit Projects 4/5, implement the lock-safe native staging correction through TDD, commit release documentation, create the deterministic version candidate, run one final integrated gate set, obtain identity-bound Oracle and Reviewer receipts, publish one immutable tag through the existing main-package workflow, and install only the checksum-verified Codex asset. Product workers never perform Git writes; the parent orchestrator alone owns the explicitly authorized commits, branch push, annotated tag, tag push, review receipt ledger, and live Codex switch.

**Tech Stack:** Windows PowerShell 7 (`pwsh`), Git, pnpm 11.9.0, Node.js 22+/TypeScript, `node:test`, Cargo/Rust, `curl.exe`, GitHub public REST API, npm registry, OpenCode CLI, Codex CLI, and `tar`.

**Global Constraints:**
- The authoritative approved design is `docs/superpowers/specs/2026-07-29-release-0.6.5-design.md`; execute every gate in its stated order and stop at the first failed mandatory gate.
- The release covers every committed product change from `v0.6.4` through the final reviewed `HEAD`, including Projects 1–5, the native-staging correction, the release design and plan, and deterministic version artifacts.
- The main package becomes exactly `0.6.5`; `package.json.ocmm.lspVersion`, `crates/ocmm-lsp/Cargo.toml`, `Cargo.lock`, Nix LSP sources, and all LSP platform package versions remain `0.3.2` and unchanged.
- Do not create an `ocmm-lsp-v*` tag or publish the native LSP lane.
- Do not change the schema, `schema.json`, lockfiles, dependencies, `.github/workflows/release.yml`, or unrelated files.
- The five active root `dist/bin/ocmm-lsp-x86_64-pc-windows-msvc.exe` processes are user processes. Never signal, suspend, terminate, or replace them through process-management commands.
- Lock-safe staging skips only a byte-identical expected target. A missing, different, unreadable, stale, or locked-different target still follows remove-and-copy behavior and any replacement failure propagates.
- Unexpected names in the `ocmm-lsp*` staging family are removed; copied non-Windows binaries receive mode `0o755`.
- Use only PowerShell 7 syntax for local commands. Do not place Bash assignment, command chaining, heredocs, `/dev/null`, or POSIX redirection in executable local blocks.
- Use `C:\Users\HUGEFI~1\AppData\Local\Temp\opencode` as the only release evidence, isolated-QA, package-staging, and download temporary root. Before any command creates a directory, verify its parent with `Test-Path -LiteralPath ... -PathType Container`.
- Do not install software. Use the existing Node, pnpm, Cargo, Git, OpenCode, Codex, `curl.exe`, and `tar` installations only.
- Do not run `pnpm install`, `npm install`, `gh`, or any package-version mutation command.
- Do not force-push, force-update a tag, rebase, amend, reset, stash, rewrite history, move a published tag, or delete an old durable Codex version.
- Product implementation subagents only edit their assigned files, run their assigned read-only verification commands, and return factual evidence plus a suggested commit message. They never stage, commit, push, tag, publish, dispatch acceptance reviewers, or mutate the live Codex installation.
- Every project-repository Git write is parent-orchestrator-owned under the user's explicit release authorization. Before each commit the parent must inspect status, full diff, recent message style, sensitive-data scan, exact staged scope, staged full diff, and staged `git diff --check`.
- Every commit uses a semantic title, one concise body paragraph, and no footer, trailer, co-author line, or AI metadata.

- Capture the exact current repo-root `deepwork-local` marketplace and Deepwork plugin state before live mutation. On switch failure, remove only partial new state and restore that exact repo-root state; keep the durable release directory and all older durable versions.
- The observed precondition is exactly installed/enabled `deepwork@deepwork-local` version `0.6.3` with repository marketplace root `C:\Users\hugefiver\source\ocmm` and cache under the effective `CODEX_HOME`. - [ ] **Step 3: Implement the minimal staging helper**

Create `scripts/stage-ocmm-lsp-binaries.ts`:

```typescript
import {
  chmodSync,
  copyFileSync,
  mkdirSync,
  readFileSync,
  readdirSync,
  rmSync,
} from "node:fs"
import { join } from "node:path"

export type ReplaceTarget = (source: string, target: string) => void

export interface StageOcmmLspBinariesOptions {
  source: string
  outDir: string
  names: readonly string[]
  platform?: NodeJS.Platform
  replaceTarget?: ReplaceTarget
}

function replaceTargetByCopy(source: string, target: string): void {
  rmSync(target, { force: true })
  copyFileSync(source, target)
}

export function stageOcmmLspBinaries(options: StageOcmmLspBinariesOptions): void {
  const platform = options.platform ?? process.platform
  const replaceTarget = options.replaceTarget ?? replaceTargetByCopy
  const names = [...new Set(options.names)]
  const expected = new Set(names)
  const sourceBytes = readFileSync(options.source)

  mkdirSync(options.outDir, { recursive: true })
  for (const entry of readdirSync(options.outDir)) {
    if (entry.startsWith("ocmm-lsp") && !expected.has(entry)) {
      rmSync(join(options.outDir, entry), { force: true })
    }
  }

  for (const name of names) {
    const target = join(options.outDir, name)
    let identical = false
    try {
      identical = sourceBytes.equals(readFileSync(target))
    } catch {
      identical = false
    }
    if (identical) continue

    replaceTarget(options.source, target)
    if (platform !== "win32") chmodSync(target, 0o755)
  }
}
```

This intentionally catches only the target-read attempt so unreadable/missing targets proceed to replacement; source-read, cleanup, replacement, copy, and mode errors all propagate.

function Get-TreeManifest([string]$root) {
  $rootFull = [IO.Path]::GetFullPath($root)
  if (-not (Test-Path -LiteralPath $rootFull -PathType Container)) { throw "tree root is missing: $rootFull" }
  $records = [Collections.Generic.List[string]]::new()
  foreach ($entry in Get-ChildItem -LiteralPath $rootFull -Force -Recurse) {
    $relative = [IO.Path]::GetRelativePath($rootFull, $entry.FullName).Replace("\", "/")
    if ($entry.LinkType) { $records.Add("L`t$relative`t$([string]::Join('|', @($entry.Target)))") }
    elseif ($entry.PSIsContainer) { $records.Add("D`t$relative") }
    else { $records.Add("F`t$relative`t$($entry.Length)`t$((Get-FileHash -LiteralPath $entry.FullName -Algorithm SHA256).Hash.ToLowerInvariant())") }
  }
  $ordered = $records.ToArray(); [Array]::Sort($ordered, [StringComparer]::Ordinal)
  $hasher = [Security.Cryptography.SHA256]::Create()
  try { $hash = ([Convert]::ToHexString($hasher.ComputeHash([Text.Encoding]::UTF8.GetBytes(($ordered -join "`n"))))).ToLowerInvariant() } finally { $hasher.Dispose() }
  [pscustomobject]@{ Records = $ordered; Hash = $hash; Count = $ordered.Count }
}

function Get-TreeManifest([string]$root) {
  $rootFull = [IO.Path]::GetFullPath($root)
  if (-not (Test-Path -LiteralPath $rootFull -PathType Container)) { throw "tree root is missing: $rootFull" }
  $records = [Collections.Generic.List[string]]::new()
  foreach ($entry in Get-ChildItem -LiteralPath $rootFull -Force -Recurse) {
    $relative = [IO.Path]::GetRelativePath($rootFull, $entry.FullName).Replace("\", "/")
    if ($entry.LinkType) { $records.Add("L`t$relative`t$([string]::Join('|', @($entry.Target)))") }
    elseif ($entry.PSIsContainer) { $records.Add("D`t$relative") }
    else { $records.Add("F`t$relative`t$($entry.Length)`t$((Get-FileHash -LiteralPath $entry.FullName -Algorithm SHA256).Hash.ToLowerInvariant())") }
  }
  $ordered = $records.ToArray(); [Array]::Sort($ordered, [StringComparer]::Ordinal)
  $hasher = [Security.Cryptography.SHA256]::Create()
  try { $hash = ([Convert]::ToHexString($hasher.ComputeHash([Text.Encoding]::UTF8.GetBytes(($ordered -join "`n"))))).ToLowerInvariant() } finally { $hasher.Dispose() }
  [pscustomobject]@{ Records = $ordered; Hash = $hash; Count = $ordered.Count }
}
function Assert-TreeEqual($expected, $actual, [string]$label) {
  if ($expected.Hash -ne $actual.Hash -or $expected.Count -ne $actual.Count -or @((Compare-Object $expected.Records $actual.Records)).Count -ne 0) { throw "$label tree mismatch" }
}

}
