# OpenCode Tool Compatibility

This host-compatibility layer maps the active role and workflow onto OpenCode's available tools without changing permissions or behavioral calibration.

Use OpenCode's currently callable task schema for permitted delegation and its available todo/notepad surface for tracking. `task_id` continues only the same child session; use background fields only when exposed and independent parent work remains. Rely on host notifications rather than polling or invented retrieval APIs. Use the exposed editing tools and LSP tools, not Codex-only tool names. Load matching skills through the host's available skill surface.
