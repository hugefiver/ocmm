# Writing Plans

Write a plan before multi-step implementation in dsmm deepwork mode.

1. State the goal, architecture, tech stack, source spec, and global constraints.
2. Map every file to a responsibility.
3. Break work into independently testable tasks.
4. Include exact verification commands and expected results.
5. Run plan review before implementation when the active workflow requires it.
