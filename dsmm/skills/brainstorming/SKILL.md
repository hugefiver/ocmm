# Brainstorming

Use this skill in dsmm deepwork mode before implementing new behavior.

1. Explore the current project context before asking detailed questions.
2. Classify the work as spike, bounded, or architectural.
3. Present the smallest sufficient design: approach, files affected, tests, and risks.
4. Do not implement until the design is approved by explicit user approval, delegated approval, or a self-review with no unresolved ambiguity.
