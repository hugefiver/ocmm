# Receiving Code Review

Treat review feedback as claims to verify, not commands to obey blindly.

1. Reproduce or inspect each finding in the current code.
2. Fix only confirmed issues within the requested scope.
3. Re-run the evidence that proves the fix.
4. Re-submit for review when required by the workflow.
