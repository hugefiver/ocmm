# Requesting Code Review

Review is evidence chosen for risk, not a fixed completion ceremony. Share the actual current diff and new files, goal, acceptance criteria, tests and real-surface evidence, constraints, and focused risk. A status label is not proof.

DSMM Reviewer is primary-model or primary-lane implementation self-review. Oracle and Oracle 2nd are external-model cross-check slots only when their caller explicitly selects an available different model; priority is not capability rank. Do not use implementation reviewers for research, design, root-cause diagnosis or plan criticism, and do not fan out every role merely because it exists. Re-request only a review affected by a substantive change or newly relevant evidence. Review never authorizes Git writes.
